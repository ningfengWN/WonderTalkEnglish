# WonderTalk English · 成人英语 V4

这是一个以日常英语训练为主的 SwiftUI iOS App。

## 学习流程
1. 泛听：不看原文，听整篇音频
2. 阅读：逐句阅读和理解
3. 跟读：示范音频、麦克风录音、回放
4. 复习：保存课程完成状态

支持导入合法使用的 MP3/M4A 课程音频、手动对齐句子时间，并使用 JSON 课程库。

## 学习账号
保留原有家庭档案入口（妈妈、女儿），但**当前只开发妈妈的英语学习功能**。通过顶部头像打开本机学习账号页，查看已完成课程、练习次数、当前课程、最近学习日期和手动 CEFR 等级。档案按 `wt.family.<profile>.*` 分别保存于本机 UserDefaults；录音按档案分别命名。保留此前 V3 的成人学习记录迁移。

**本版本没有云端账号注册或跨设备同步**，删除 App 前请备份数据。不要将 API 密钥或个人录音提交到 GitHub。

## 资源说明
当前随包的课程音频为合成演示音频，**不是真人 VOA 录音**。真人录音需在许可允许时导入。

## Xcode 验证
该分支尚未在 Xcode 环境中编译。请在 iPhone 模拟器验证：家庭档案选择、妈妈学习账号、泛听、课程导入、逐句跟读、录音权限、录音回放、完成进度恢复。
