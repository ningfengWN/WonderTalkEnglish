# WonderTalk English · 成人英语 V4

这是一个以日常英语训练为主的 SwiftUI iOS App。

## 学习流程
1. 泛听：不看原文，听整篇音频
2. 阅读：逐句阅读和理解
3. 跟读：示范音频、麦克风录音、回放
4. 复习：保存课程完成状态

支持导入合法使用的 MP3/M4A 课程音频、手动对齐句子时间，并使用 JSON 课程库。

## 学习账号
保留原有家庭档案入口（妈妈、女儿），但**当前只开发妈妈的英语学习功能**。通过顶部头像打开本机学习账号页，查看已完成课程、练习次数、当前课程、最近学习日期和手动 CEFR 等级。档案按 `wt.family.<profile>.*` 分别保存于本机 UserDefaults；录音按档案分别命名。保留此前 V3 的成人学习记录迁移。

**本版本没有云端账号注册或跨设备同步**，删除 App 前请备份数据。不要将 API 密钥或个人录音提交到 GitHub。

## 资源说明
当前随包的课程音频为合成演示音频，**不是真人 VOA 录音**。真人录音需在许可允许时导入。

## Xcode 验证
该分支尚未在 Xcode 环境中编译。请在 iPhone 模拟器验证：家庭档案选择、妈妈学习账号、泛听、课程导入、逐句跟读、录音权限、录音回放、完成进度恢复。


## 标准化学习资料库 V1 · 40 份

`WonderTalkEnglish/Lessons/learning_catalog_v1.json` 收录 40 条外部学习资料索引，包含：

- 日常听说 20 条 (E01–E20)
- 家庭亲子 7 条 (F01–F07)
- 财经新闻 5 条 (N01–N05)
- 财报和美联储 5 条 (P01–P05)
- 欧洲历史 3 条 (H01–H03)

每条记录包含稳定 ID、分类、原始标题、话题、来源、HTTPS 链接、建议 CEFR 范围、学习模式、材料状态及版权说明。链接是资料入口，不是已经授权的音频直链。等级为编辑建议，个别资料的具体难度仍应以来源页面为准。

### 使用步骤

1. 在 App 的课程菜单中按分类选择材料。
2. 点击“打开官方课程 / 原始资料”，在原网站收听、阅读。
3. 如果已有合法使用的逐句英文原文，可使用“导入课程原文”；如果已有合法使用的本地 MP3/M4A，可导入音频。
4. 导入音频及原文之后，使用现有逐句时间对齐功能，才能在 App 内精确地播放句子和跟读。
5. 日常和家庭类材料以说和互动为目标；财经与历史类材料以听读理解为目标。

资料库为索引型目录，**不包含第三方逐字稿或音频文件**，不对外部资源可下载性、付费状态或持久可用性作保证。导入内容时请核实来源及许可。

启动时课程仓库会把新随包材料与本机既有课程合并，按稳定 ID 去重，并保留用户已导入的音频、逐句原文、时间对齐和个人学习进度。

**构建状态：**本次提交尚未在 macOS Xcode / iOS 模拟器中完成编译与运行验证。


## 个人离线素材下载工具（新增）

此工具用于在**自己的 Mac 上**下载符合使用条件的资料，不把第三方音频或逐字稿推送到公开 GitHub 仓库。

在仓库根目录运行：

```bash
python3 tools/download_study_materials.py \
  --ids h01 h02 h03 e02 \
  --agree-noncommercial
```

默认在 `PrivateStudyDownloads/` 生成各课程目录、来源 HTML、元数据及结果报告；对于耶鲁课程尝试提取个人学习用文字稿，对于网页中公开暴露直接 MP3/M4A 地址的资料尝试下载原音频。某些站点使用动态加载或有访问限制，可能无法自动找到音频，请查看 `download_report.json`，必要时使用官方页面的下载入口。需要联网在 Mac 上运行，本脚本未在当前无外网下载能力的执行环境中完成端到端验证。

导入 App：在 iPhone/iPad 文件 App 中取得合法保存的 MP3/M4A → 打开相应课程 → 导入本地音频；文字稿可按句分行粘贴到“导入课程原文”。音频与文字稿仍需逐句时间对齐。下载的 `source_page.html` 是私人离线保存的网页副本，不代表已清理成可直接导入的逐句原文。

**许可提醒：**耶鲁课程多数为 CC BY-NC-SA 3.0（注意第三方内容及署名），ELLLO 允许一定范围的非商业教育使用；British Council 主要允许个人非商业使用，不得擅自重新发布或改编；商业新闻、公司财报音视频及视频平台素材需按各自条款处理。脚本默认拒绝自动下载这些其他来源，不绕过版权保护、付费墙或技术限制。使用前阅读各网站许可。下载文件不可提交到公共仓库。
