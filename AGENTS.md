# Agent guidance for WonderTalkEnglish

When asked to discover, verify, download, transcribe, align, or import original English listening courses, follow [English Listening Material Acquisition](.agents/skills/english-listening-material-acquisition/SKILL.md).

Do not claim audio is downloaded or playback is tested unless the file was actually retrieved and verified. Preserve the distinction between external catalog links and licensed offline audio. Keep third-party audio/transcripts and private recordings out of public git unless explicitly licensed for redistribution.
