# 本地课程字幕与音频批量导入

课程管理 → **批量导入本地课程资料包（字幕 + 音频）**。

该入口接收本地 JSON（formatVersion = 1），每个 item 包含：
- `id`：已有课程编号（如 e18）
- `sourceURL`：必须与课程目录原始来源网址完全一致
- `lines`：可选，逐句英文数组（不带未朗读的说话人标签）
- `audioFilename`、`audioBase64`：可选，音频文件名和 base64 音频

例子（示意文本，不含第三方版权资料）：

```json
{
  "formatVersion": 1,
  "items": [
    {
      "id": "e18",
      "sourceURL": "https://example.com/your-licensed-lesson",
      "lines": ["Hello.", "How are you?"]
    }
  ]
}
```

**注意**：示例中的 sourceURL 只是占位；实际导入时必须使用课程目录对应的来源 URL。

- 仅在设备本地解码与保存；不将第三方音频和完整文字稿提交至 GitHub。
- 默认只填补没有文字稿/音频的课程；也可显式选择覆盖已有资料。
- 如果覆盖文字稿，原有句子时间戳会被清空，需要重新运行自动逐句对齐。
- 已有课程必须同时通过 ID 与来源 URL 校验；不匹配、无效音频会被跳过并报告。
- 导入后，进入 **自动 / 手动逐句对齐** 生成时间戳，试听确认后保存。
- 音频匹配基于来源网址的课程序号与文件名，并不等于语音内容已经验证；特别是重复版本或剪辑版，需要人工试听确认。
- 本功能未在 Xcode 真机或模拟器编译验证，首次使用前建议备份本地课程记录。
